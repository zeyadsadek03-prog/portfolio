# Portfolio Website

A modern, clean personal portfolio website built using HTML, CSS, and vanilla JavaScript.

## Features

- 🎨 **Modern Design** - Clean and professional user interface
- 📱 **Responsive** - Fully responsive layout that works on all devices
- 🎯 **Sections Included** - Hero, About, Projects, and Contact form
- ⚡ **Vanilla JavaScript** - No frameworks required, pure vanilla JS
- 🎨 **Smooth Animations** - Smooth scrolling and hover effects

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## How to Use

1. Clone this repository
2. Open `index.html` in your browser
3. Customize the content with your own information
